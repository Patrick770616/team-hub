# 💬 團隊中樞

把這台電腦上的 Claude Code 對話、Gemini 和網頁版的舊對話拉進同一個群組討論，也能一對一私聊，像 LINE 一樣。這是獨立的小程式，不需要虛擬辦公室。

## 特色

- **一個聊天室，好幾個 AI**：Claude、Gemini、本機模型、網頁版的舊對話，都能同場討論、互相回應。
- **走訂閱，不走按量計費**：Claude 一律用本機的 Claude Code 和你的訂閱，不會動到按 Token 計費的 API。
- **資料夾跟著群組走**：每個群組一個專案資料夾，助手只看過濾掉機密的唯讀副本。
- **助手能動手，但你說了算**：改檔、跑指令都要你在畫面上按「允許」（附白話說明、改前自動備份），也可以選安全放行或全自動。
- **省額度**：長對話自動摘要重開，很久沒說話的成員只補讀摘要＋最近 12 則，另有每日 Token 上限。
- **只在你的電腦上跑**：只聽本機、要密碼登入、機密檔一律不收；沒有雲端、沒有帳號。
- **設定都在畫面上**：連接其他 AI、資料夾、權限、截圖都不用改設定檔。

## 怎麼開

雙擊桌面的「團隊中樞」捷徑（或資料夾裡的 `團隊中樞.vbs`）。它在背景執行，沒有黑色視窗；第一次會先安裝套件（要網路，約一分鐘），之後瀏覽器會自動打開 `http://localhost:8300` 並登入。要關掉就按頁面右上角的「⏻ 關閉」；它自己當掉會在 3 秒後自動重開。已經開著時再點捷徑，只會再打開瀏覽器。訊息和這次的密碼（別的瀏覽器第一次開要輸入）在 `data/server.log`。想看著黑色視窗跑，仍可雙擊 `啟動團隊中樞.bat`。

需要：Node.js 20.6 以上（Windows）；Claude 成員要裝好 Claude Code 並用 Claude 訂閱登入（也可以在「🔌 加入其他 AI」裡登入）；Gemini 的免費金鑰（Google AI Studio）在同一個視窗填就好。

從 GitHub 拿到的人：下載或 `git clone` 之後，雙擊資料夾裡的 `團隊中樞.vbs` 就會啟動；想要桌面捷徑，對它按右鍵「傳送到 → 桌面（建立捷徑）」。

## 能做什麼

團隊中樞讓你把好幾個 AI 放進同一個聊天室，像 LINE 一樣一起討論，也能一對一私聊。

### 成員從哪來
- **📥 綁定對話**：列出這台電腦上的 Claude Code 對話，選一個變成成員。它以「分身」加入：記得原本聊過的內容，但這裡說的話不會回到原本的對話（每次發言前後都比對原對話檔案，訊息下面會標「✅ 原對話未變動」）。
- **🔌 加入其他 AI**：在畫面上設定 Claude 登入、本機 Ollama、OpenAI 相容服務、Antigravity、Gemini 金鑰，可以直接測試連線，不用手動改 .env（後面三種只能文字對話）。
- **🤖 新增助手**：全新的 Claude 助手，你替它寫角色（可請 Gemini 幫你生成），可選模型、是否能上網。
- **Gemini**：內建成員。送給 Gemini 的內容會先遮掉金鑰和本機路徑。
- **📚 匯入網頁版對話**：claude.ai、ChatGPT、Gemini 網頁版的對話，用官方匯出檔或直接貼上，Gemini 整理成摘要後變成一位成員。
- 每位成員的頭像是名字第一個字，底色各不相同，方便一眼分辨。

### 聊天
- **回覆精簡**：助手被要求先講結論，動手前後各一句話，不重複確認卡上已經有的資訊。
- **群組和私聊**：群組可以「＠ 點名」（@ 誰誰回答，@全部 是每個人）或「🔁 自主協商」（大家輪流發言，最多 3 輪，都同意就提前結束）。「👥 成員」可以加人或移出。
- **📎 附件**：圖片、PDF、文字檔，可以按 📸 直接截一個視窗或螢幕、貼上截圖，或拖進聊天室。
- **💾 總結並寫入記憶**：Gemini 把討論整理成結論，寫進每位 Claude 成員的專案記憶資料夾（`~/.claude/projects/<專案>/memory/`），原本的對話下次開就記得。

### 專案資料夾（跟著群組走）
- 每個群組有自己的專案資料夾（建群組時指定，之後可用「📁」改）。群組裡的 Claude 助手讀的和改的都是它；不需要的群組可以明確選「不需要資料夾」。
- 助手只看到資料夾的過濾副本：金鑰、密碼檔和隱藏檔不在裡面。
- 綁定的 Claude 對話如果自己已有不同的專案資料夾，加入群組時會先列出兩邊的差異，讓你選「以群組為準」或「保留原本的」。目前不會自動合併檔案。
- 助手的對話記憶每個聊天室各一份，不會把 A 專案的事帶到 B 專案。

### 讓助手動手（可選，預設全關）
- **✋ 動手權限**：助手可以改檔、寫檔、執行指令。每一步都在畫面上出現確認卡，附一句白話說明（為什麼要做、做完會怎樣），你按「允許」才會執行；改檔前會自動備份。
- **🛡 安全指令放行**：看檔案、查版本這類不會改東西的指令直接執行。
- **⚡ 全自動**：不危險的動作都直接執行（每回合上限 40 個）。危險指令、金鑰檔、資料夾以外的路徑，一律還是要問或直接擋下。
- 私聊的權限跟著助手；群組的權限每個群組、每位成員分開設定（「✋ 權限」）。

### 省額度
- **補讀量上限**：很久沒發言的 Claude 成員只補讀「前情摘要＋最近 12 則」。
- **自動重開對話**：Claude 對話累積太長或閒置太久，會用摘要重新開始，聊天紀錄不受影響。
- **🔢 每日 Token 上限**：見下方。

## 安全

- **只有這台電腦打得開**：只聽 127.0.0.1，只認 `localhost:8300`／`127.0.0.1:8300` 這兩個名字；所有操作要從團隊中樞自己的頁面送出，別的網站送來的一律拒絕。
- **🔑 啟動密碼**：每次啟動換一組（`XXXX-XXXX`），寫在 `data/server.log`。自動打開的瀏覽器用一次性連結登入；別的瀏覽器第一次開要輸入。登入後 7 天內不用再輸入，重開也一樣。一分鐘內錯 5 次要等一分鐘。
- **🔒 機密檔一律不收**：隱藏檔（`.env` 這類）、金鑰檔、檔名有 secret／password／credential 的檔案（規則在 `lib/secrets.js`，之後讀資料夾也用同一個函式）。圖片沒辦法遮蔽，含密碼的截圖請先打碼。
- **🔢 每日 Token 上限**：每次回覆的 Token（輸入加輸出）都算進今天的用量，每天自動歸零。預設開啟、上限 3,000,000，在「⚙️ 設定」可以改或關掉。到上限就不會開始新的回覆。Claude 分身每次都會讀進原本的整段對話，很長的對話一次可能就用掉十幾萬。

## 檔案

- `團隊中樞.vbs`＋`launcher.js`：背景啟動（自動重開，紀錄在 data/server.log）
- `啟動團隊中樞.bat`：有黑色視窗的啟動方式
- `server.js`：伺服器、登入、每日 Token 上限
- `index.html`：頁面
- `lib/hub.js`：群組、私聊、分身、遮蔽、寫入記憶
- `lib/hubhttp.js`：API
- `lib/aisetup.js`：在畫面上設定其他 AI（寫進 .env）
- `lib/act.js`、`lib/actserver.js`：助手動手的工具和危險指令判斷
- `lib/llm.js`：呼叫 Claude Code、Gemini 等 AI
- `lib/webimport.js`：讀網頁版的匯出檔
- `lib/secrets.js`：哪些檔案算機密
- `test.js`：測試（`node test.js`，不呼叫任何 AI）
- `.env`：金鑰和模型設定（不進 git）
- `data/`：聊天紀錄、附件、登入紀錄、用量（不進 git）

這份程式是從虛擬辦公室（AI office）的「💬 團隊通訊中樞」複製出來的，之後兩邊各改各的。
