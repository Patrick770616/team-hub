# 💬 團隊中樞

把這台電腦上的 Claude Code 對話、Gemini 和網頁版的舊對話拉進同一個群組討論，也能一對一私聊，像 LINE 一樣。這是獨立的小程式，不需要虛擬辦公室。

## 怎麼開

雙擊 `啟動團隊中樞.bat`。第一次會先安裝套件（要網路，約一分鐘），之後瀏覽器會自動打開 `http://localhost:8300` 並登入。黑色視窗關掉，團隊中樞就停了；它自己當掉會在 3 秒後自動重開。

需要：Node.js 20.6 以上；Claude 成員要裝好 Claude Code 並用 Claude 訂閱登入；Gemini 要在 `.env` 填 `GEMINI_API_KEY`（Google AI Studio 的免費金鑰）。

## 能做什麼

- **📥 綁定對話**：列出這台電腦上的 Claude Code 對話，選一個變成成員。它以「分身」加入：記得原本聊過的內容，但這裡說的話不會回到原本的對話（每次發言前後都比對原對話檔案，訊息下面會標「✅ 原對話未變動」）。分身只能看檔案，不能改檔案或執行指令。
- **Gemini**：內建成員。送給 Gemini 的內容會先遮掉金鑰和本機路徑。
- **📚 匯入網頁版對話**：claude.ai、ChatGPT、Gemini 網頁版的對話，用官方匯出檔或直接貼上，Gemini 整理成摘要後變成一位成員。
- **群組和私聊**：群組可以「＠ 點名」（@ 誰誰回答，@全部 是每個人）或「🔁 自主協商」（大家輪流發言，最多 3 輪，都同意就提前結束）。「👥 成員」可以加人或移出。
- **📎 附件**：圖片、PDF、文字檔，可以貼上截圖或拖進聊天室。
- **📁 群組資料夾**：每個群組有自己的專案資料夾（建群組時指定，之後可改），群組裡的 Claude 助手讀的和改的都是它；沒有群組資料夾才用助手自己的資料夾。「✋ 權限」（可動手／安全指令放行／全自動）也是每個群組分開設定。綁定的 Claude 對話如果自己已有不同的專案資料夾，加入群組時會先問你「以群組為準」或「保留原本的」，並列出兩邊的差異。
- **💾 總結並寫入記憶**：Gemini 把討論整理成結論，寫進每位 Claude 成員的專案記憶資料夾（`~/.claude/projects/<專案>/memory/`），原本的對話下次開就記得；正開著的視窗可以按「📋 複製熱更新指令」貼給它。

## 安全

- **只有這台電腦打得開**：只聽 127.0.0.1，只認 `localhost:8300`／`127.0.0.1:8300` 這兩個名字；所有操作要從團隊中樞自己的頁面送出，別的網站送來的一律拒絕。
- **🔑 啟動密碼**：每次啟動換一組（`XXXX-XXXX`），印在黑色視窗裡。自動打開的瀏覽器用一次性連結登入；別的瀏覽器第一次開要輸入。登入後 7 天內不用再輸入，重開也一樣。一分鐘內錯 5 次要等一分鐘。
- **🔒 機密檔一律不收**：隱藏檔（`.env` 這類）、金鑰檔、檔名有 secret／password／credential 的檔案（規則在 `lib/secrets.js`，之後讀資料夾也用同一個函式）。圖片沒辦法遮蔽，含密碼的截圖請先打碼。
- **🔢 每日 Token 上限**：每次回覆的 Token（輸入加輸出）都算進今天的用量，每天自動歸零。預設開啟、上限 3,000,000，在「⚙️ 設定」可以改或關掉。到上限就不會開始新的回覆。Claude 分身每次都會讀進原本的整段對話，很長的對話一次可能就用掉十幾萬。

## 檔案

- `啟動團隊中樞.bat`：啟動（自動重開）
- `server.js`：伺服器、登入、每日 Token 上限
- `index.html`：頁面
- `lib/hub.js`：群組、私聊、分身、遮蔽、寫入記憶
- `lib/hubhttp.js`：API
- `lib/llm.js`：呼叫 Claude Code、Gemini 等 AI
- `lib/webimport.js`：讀網頁版的匯出檔
- `lib/secrets.js`：哪些檔案算機密
- `test.js`：測試（`node test.js`，不呼叫任何 AI）
- `.env`：金鑰和模型設定（不進 git）
- `data/`：聊天紀錄、附件、登入紀錄、用量（不進 git）

這份程式是從虛擬辦公室（AI office）的「💬 團隊通訊中樞」複製出來的，之後兩邊各改各的。
